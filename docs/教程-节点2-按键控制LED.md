## 1. 看图找键

![按键电路](images/sch_p3_keys.png)

**怎么读**：原理图第 3 页（红框是一个按键的完整电路）：按键左脚接 GND，右脚一路经 **10K 电阻上拉到 3V3**，
一路就是网络 `KEY1`。所以：**松开 = 被上拉成高电平，按下 = 直接接地变低电平（低电平有效）**。
电容 C25 是硬件消抖的辅助（软件消抖还是要做，见版本 B）。

![引脚表](images/sch_p7_key_pin.png)

**怎么读**：第 7 页引脚表：**KEY1 = PD13、KEY2 = PD14、KEY3 = PD15**。
（红框圈的三行。）本节点只用 KEY1 和 LED1，其余照公式举一反三。

## 2. 原理

**和节点一比，只多了一件事：读引脚电平。**

| 步骤 | 做什么 | 要点 |
|---|---|---|
| 开时钟 | 同节点一 | `AHB1ENR` bit3 |
| PD13 配输入 | MODER **[27:26]** = 00（13号脚×2=26） | 板上已有外部 10K 上拉，**PUPDR 不用配**（保持 00 无上下拉） |
| 读电平 | **GPIOx_IDR**（输入数据寄存器） | 读 bit13：**0=按下，1=松开** |

![PUPDR](images/rm_p284_pupdr.png)

**怎么读**：第 284 页 `GPIOx_PUPDR`——每脚 2 位：00 无上下拉 / 01 上拉 / 10 下拉。
板上已经焊了 10K 上拉电阻，芯片内部再配上拉是多余的，保持默认 00。

![IDR](images/rm_p285_idr.png)

**怎么读**：第 285 页 `GPIOx_IDR`——每脚 1 位，**只读**。bit 号 = 脚号：PD13 → bit13。
**IDR 和 ODR 的区别**：ODR 是"你让它输出什么"（输出锁存器），IDR 是"引脚现在真实是什么电平"。
读按键永远用 IDR。

**消抖（版本 B 才需要）**：机械按键按下瞬间会弹跳 5~20ms（电平反复横跳）。
软件消抖 = 检测到按下后 **等 20ms 再看一眼**，还是按下才算数；然后**等松手**再继续，防止一次长按被算成多次。

## 3. 寄存器版

### 版本 A：按住亮、松开灭（先做这个）

```c
#include "stm32f4xx.h"

int main(void)
{
    SystemCoreClockUpdate();

    RCC->AHB1ENR |= RCC_AHB1ENR_GPIODEN;   /* 开 GPIOD 时钟（同节点一） */

    GPIOD->MODER &= ~(3UL << 26);          /* PD13 输入：清 [27:26] 成 00（输入不用写1） */
    GPIOD->MODER &= ~(3UL << 20);          /* PD10 输出：先清 [21:20] */
    GPIOD->MODER |=  (1UL << 20);          /* 再写 01 */

    GPIOD->BSRR = GPIO_BSRR_BR10;          /* 上电先灭 */

    while (1)
    {
        if (GPIOD->IDR & GPIO_IDR_ID13)    /* 读 bit13：1=松开 */
            GPIOD->BSRR = GPIO_BSRR_BR10;  /* 灭 */
        else                               /* 0=按下 */
            GPIOD->BSRR = GPIO_BSRR_BS10;  /* 亮 */
    }
}
```

### 版本 B：按一下翻转一次（版本 A 验收过了再做）

在版本 A 基础上加三招：**消抖 20ms → 翻转 → 等松手**。
把 `while(1)` 换成下面这样（`delay_ms` 从 `chapters/ch1_led.c` 原样搬，文件开头加 `uint32_t led = 0;`）：

```c
    uint32_t led = 0;                      /* 记住灯当前状态 */

    while (1)
    {
        if ((GPIOD->IDR & GPIO_IDR_ID13) == 0)      /* 检测到按下 */
        {
            delay_ms(20);                           /* 消抖：跳过弹跳期 */
            if ((GPIOD->IDR & GPIO_IDR_ID13) == 0)  /* 还是按下 = 真按 */
            {
                led = !led;                         /* 翻转状态 */
                if (led)
                    GPIOD->BSRR = GPIO_BSRR_BS10;   /* 亮 */
                else
                    GPIOD->BSRR = GPIO_BSRR_BR10;   /* 灭 */
                while ((GPIOD->IDR & GPIO_IDR_ID13) == 0) { }  /* 等松手 */
            }
        }
    }
```

## 5. 验收

| 版本 | 现象 | 通关标准 |
|---|---|---|
| A | 按住 KEY1 → 红灯亮；松开 → 灭 | 手速再快也跟手，无延迟感 |
| B | 每按一下，灯翻转一次 | 长按只算一次；快速连按每次都响应 |

**常见翻车预告**：①灯常亮不跟手 → 你读的是 ODR 不是 IDR；②按一下翻转好几次 → 忘了消抖/等松手；③怎么按都没反应 → MODER 忘了清 [27:26]，或时钟没开。
