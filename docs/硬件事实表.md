# 硬件事实表 · STM32F407 主控板 V1.0

> 信源标注：【原理图】= 导师提供的 F407VET6(1).pdf（7 页原理图，嘉立清 EDA，V1.0，2026-07 更新）
> 引脚分配：原理图第 7 页"引脚分配"，坐标提取 + 视觉读图**双源一致**（2026-10-13 核实）
> 【⚠️待实测】= 板到手后必须实物核验，不许当已确认用

## 芯片与时钟

| 项目 | 值 | 来源 |
|---|---|---|
| MCU | STM32F407VET6（LQFP100） | 【原理图】页2 U1 |
| Flash / SRAM | 512KB / 192KB（128KB 主 + 64KB CCM） | 【手册】器件特性 |
| HSE 晶振 | **8MHz**（X1，12pF×2） | 【原理图】页2，【⚠️待实测】丝印 |
| LSE 晶振 | 32.768kHz（X2，20pF×2） | 【原理图】页2 |
| 时钟注意 | DFP 系统模板默认 HSE_VALUE=25MHz；旧项目（串口服务器 ZGT6）是 **25MHz 晶振**，PLL 配置**不可照搬**；配 PLL 时必须显式 `#define HSE_VALUE 8000000` | 【实测】旧工程 Cpu 行 CLOCK(25000000) |
| 电源 | VIN→TPS5430( DC-DC )→5V→1117-3.3→3V3 | 【原理图】页1 |
| SWD | SWCLK/SWDIO/GND/3V3/BOOT0/BOOT1 排针 H4 | 【原理图】页2 |
| BOOT0/BOOT1 | 各经 10K 下拉到 GND（正常从 Flash 启动） | 【原理图】页2 R7/R8 |

## 引脚分配总表（第 7 页，60 个网络）

### 用户外设

| 网络 | 引脚 | 说明 |
|---|---|---|
| LED1 | PD10 | PD10→4.7K(R9)→LED1→GND，**高电平点亮**（页3放大图+坐标双源核实） |
| LED2 | PD11 | 同上结构（R14），高电平点亮 |
| LED3 | PD12 | 同上结构（R20），高电平点亮 |
| KEY1 | PD13 | SW2；外部 10K 上拉 3V3，按下接地，**低电平有效** |
| KEY2 | PD14 | SW3；同上（页3坐标核实 SW3=KEY2） |
| KEY3 | PD15 | SW4；同上 |
| KEY4 | ？ | SW5 存在但**引脚表无映射**，【⚠️待实测】全引脚扫描定位 |
| NRST | - | SW6 复位键 |
| WKUP | PA0 | SW7 唤醒键 |
| BUZZER | PE8 | Q1 三极管驱动，【⚠️待实测】有效电平（继电器/蜂鸣器极性教训：图纸与实物可能相反） |
| RELAY | ？ | Q2 驱动 SRD-5VDC-SL-C，页7引脚表**未列出**，【⚠️待实测】 |
| CH340_TX | PA10 | CH340N 的 TXD→MCU RX（USART1_RX） |
| CH340_RX | PA9 | CH340N 的 RXD←MCU TX（USART1_TX），USB-C 虚拟串口 |
| USB_DP/DN | PA12/PA11 | USB OTG FS |

### I2C / I2S 外设

| 网络 | 引脚 | 说明 |
|---|---|---|
| AT24C02_SCL/SDA | PB10/PB11 | EEPROM，**硬件 I2C2**（AF4） |
| AHT20_SCL/SDA | PE2/PE3 | 温湿度，**非硬件 I2C 引脚→软件模拟 I2C** |
| ES8388（音频） | SCL=PB6 SDA=PB7 | 硬件 I2C1（AF4） |
| ES8388 I2S | MCLK=PC6 SCLK=PB13 SD=PB15 WS=PB12 EXT_SD=PB14 | I2S2/SPI2 系（AF5/AF6） |
| ES_CTR | PE4 | 功放使能 GPIO |

### SPI / ECAP 外设

| 网络 | 引脚 | 说明 |
|---|---|---|
| FLA_CS/SCK/MISO/MOSI | PA4/PA5/PA6/PA7 | W25Q16 Flash，**硬件 SPI1**（AF5） |
| LCD_SCK/MOSI/MISO | PB3/PB5/PB4 | 屏幕，SPI1 的**重映射脚**（AF5）⚠️与 Flash 共享 SPI1 外设，同时用需切换 AF 或软件 SPI，节点6实测 |
| LCD_DC | PB0 | 数据/命令选择 GPIO |
| LCD_CS | PA15 | 片选 GPIO |
| LCD_RST | PC7 | 复位 GPIO |
| LCD_LED | PB1 | 背光 GPIO |
| TP_CLK/CS/DIN/DO/IRQ | PE10/PE12/PE13/PE14/PE15 | 触摸（大概率 XPT2046），【⚠️待实测】屏背面丝印 |
| IMU_CS/CLK/MOSI/MISO | PC3/PC0/PC5/PC4 | ICM-42688-P，全非硬件 SPI 脚→**软件 SPI** |
| SDIO D0-D3/CMD/SCK/CD | PC8/PC9/PC10/PC11/PD2/PC12/PD3 | TF 卡，硬件 SDIO |
| EC11_A/B/KEY | PE9/PE11/PE7 | 旋转编码器 GPIO |

### UART / CAN 外设

| 网络 | 引脚 | 说明 |
|---|---|---|
| RS485_TX/RX | PD5/PD6 | USART2（AF7），DIR=PE1 方向控制 |
| RS232_TX/RX | PA0/PA1 | UART4（AF8） |
| CAN_TX/RX | PD1/PD0 | CAN1（AF9） |
| ESP_TX/ESP_RX | PD9/PD8 | USART3（AF7）接 ESP8266-01S |

### 空闲引脚

PE0、PD4、PD7（页7未分配）；H9 排针引出：PE1/PB7/PA0/PE5/PA2/PC13/PB6/PA1/PE6/PA3 + 5V/GND。

## 与旧项目（串口服务器 ZGT6）的差异

| 项目 | 旧项目 | 本板 |
|---|---|---|
| 型号/封装 | F407ZGTx LQFP144 | F407VET6 LQFP100 |
| HSE | 25MHz | 8MHz（原理图） |
| LED | -（无用户 LED） | PD10/11/12 高电平亮 |
| ESP8266 | USART3 PB10/11 | USART3 PD8/9 |
| 屏/LVGL | **无**（无可复用代码） | ST7789 SPI |
