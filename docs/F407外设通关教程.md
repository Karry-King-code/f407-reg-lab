# 节点一 · 点亮 LED 灯 ✅

## 1. 看图找灯

![LED1 电路](images/sch_p3_led1.png)

**怎么读**：原理图第 3 页。电流方向：PD10 → LED → 4.7K → GND，所以 **PD10 输出高电平灯亮**。
⚠️ 与 F103 板相反。位号 LED3 ≠ 网络名 LED1，别混。

![引脚分配](images/sch_p7_led_pin.png)

**怎么读**：第 7 页：**LED1 = PD10**（红）、LED2 = PD11（绿）、LED3 = PD12（蓝）。

## 2. 原理

**四步流程**：确定引脚 → 开时钟 → 配输出 → 亮灭交替。F1 → F4 的变化：

| 步骤 | F103 | F407 |
|---|---|---|
| 开 GPIO 时钟 | `RCC->APB2ENR` | `RCC->AHB1ENR`（换域了） |
| 配输入/输出 | CRL/CRH 每脚 4 位 | **没了**，用 MODER/OTYPER/OSPEEDR/PUPDR 四个寄存器 |
| 输出电平 | BSRR / BRR / ODR | **只有 BSRR**（BRR 没了） |

### 2.1 开时钟

![RCC_AHB1ENR](images/rm_p244_ahb1enr.png)

**怎么读**：RM0090 中文版第 244 页，**bit3 = GPIODEN**，写 1 给 GPIOD 供电。（表头在第 243 页。）

### 2.2 配输出

![GPIOx_MODER](images/rm_p283_moder.png)

**怎么读**：第 283 页 `GPIOx_MODER`——**每脚 2 位**：00 输入 / 01 输出 / 10 复用 / 11 模拟。
PD10 占 **bit[21:20]**（脚号×2=起始位；21 高位格、20 低位格）。
`1<<20` 写入 01=输出；`1<<21` 会写成 10=复用——错一位就是另一种模式，编译器不报错。
复位默认全 0 = 输入（**只听不说，忘了配灯永远不亮**——我们真踩过）。
（OTYPER 第 283 页、OSPEEDR/PUPDR 第 284 页，复位默认=推挽低速无拉，本节点不用写。）

### 2.3 亮与灭

![GPIOx_BSRR](images/rm_p286_bsrr.png)

**怎么读**：第 286 页 `GPIOx_BSRR`——低 16 位 BSx 写 1 = 高；高 16 位 BRx 写 1 = 低；写 0 无效。
`BS10`（bit10）= 亮，`BR10`（bit26）= 灭。一次写完不读旧值 = **原子操作**。
`|=` 是读-改-写，初始化用没风险；主循环翻电平用 BSRR。

### 2.4 延时

![时钟树](images/rm_p217_clocktree.png)

**怎么读**：第 217 页时钟树 + 第 219 页原话——复位默认 **HSI 16MHz**。
1ms = 16000 个时钟（直连 HCLK）或 2000 个（HCLK÷8，CTRL 不置 bit2），两种都行，参数配套即可。
时钟先不配 PLL——时钟节点再上 168MHz（必须实证晶振 8MHz、显式 `HSE_VALUE=8000000`）。

## 3. 寄存器版

| 寄存器 | 地址 | 干什么 |
|---|---|---|
| `RCC->AHB1ENR` | 0x40023830 | `\|= 1<<3` 开 GPIOD |
| `GPIOD->MODER` | 0x40020C00 | 先 `&= ~(3<<20)` 再 `\|= (1<<20)` |
| `GPIOD->BSRR` | 0x40020C18 | 亮 `1<<10`，灭 `1<<26` |

```c
int main(void)
{
    SystemCoreClockUpdate();

    RCC->AHB1ENR |= RCC_AHB1ENR_GPIODEN;        /* 开时钟 */

    GPIOD->MODER &= ~(3UL << 20);               /* 清 [21:20] */
    GPIOD->MODER |=  (1UL << 20);               /* 输出 */

    GPIOD->BSRR = GPIO_BSRR_BR10;               /* 上电先灭 */

    while (1)
    {
        GPIOD->BSRR = GPIO_BSRR_BR10;           /* 灭 */
        delay_ms(500);
        GPIOD->BSRR = GPIO_BSRR_BS10;           /* 亮 */
        delay_ms(500);
    }
}
```

`delay_ms` 用 SysTick（原理同 F103，LOAD 填 16000−1 直连或 2000−1 走 ÷8，配套就行）。
**扩展**：双灯照公式——PD11 用 `3<<22`/`1<<22`/`BS11`/`BR11`。

**验收**：0 错 0 警（≈700~800B）→ 红灯 500ms 闪、上电先灭。

## 4. HAL 版

| 你写的 | 它替你写的 |
|---|---|
| `__HAL_RCC_GPIOD_CLK_ENABLE()` | `AHB1ENR \|= 1<<3` |
| `HAL_GPIO_Init(GPIOD, &...)` | MODER/OTYPER/OSPEEDR/PUPDR 四连写 |
| `HAL_GPIO_WritePin(...SET/RESET)` | BSRR 置位/清零 |
| `HAL_Delay(500)` | SysTick 1ms 中断累计 uwTick 查差值 |

```c
int main(void)
{
  GPIO_InitTypeDef GPIO_InitStruct = {0};

  HAL_Init();                     /* SysTick 1ms 心跳 */

  __HAL_RCC_GPIOD_CLK_ENABLE();

  GPIO_InitStruct.Pin   = GPIO_PIN_10;          /* PD10 */
  GPIO_InitStruct.Mode  = GPIO_MODE_OUTPUT_PP;  /* 推挽输出 */
  GPIO_InitStruct.Pull  = GPIO_NOPULL;
  GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;
  HAL_GPIO_Init(GPIOD, &GPIO_InitStruct);

  HAL_GPIO_WritePin(GPIOD, GPIO_PIN_10, GPIO_PIN_RESET);   /* 上电先灭 */

  while (1)
  {
    HAL_GPIO_WritePin(GPIOD, GPIO_PIN_10, GPIO_PIN_RESET);  /* 灭 */
    HAL_Delay(500);
    HAL_GPIO_WritePin(GPIOD, GPIO_PIN_10, GPIO_PIN_SET);    /* 亮 */
    HAL_Delay(500);
  }
}
```

**时钟不用写**：复位默认 HSI 16MHz。F103 板那份 `HSI/2×16=64MHz` 在 F4 编译不过（`RCC_HSE_PREDIV_DIV1` 等是 F1 专属宏），整个删掉。

**验收**：0 错 0 警（≈3.2KB）→ 现象与寄存器版一致。

## 5. 翻车实录

| 现象 | 真因 | 解法 |
|---|---|---|
| 编译 0 错，灯不亮 | 没配 MODER，还是输入模式 | 补"先清后写"两行 |
| 改了代码，烧完还是老现象 | LOAD 不自动编译，烧的旧 hex | **先 F7 再 LOAD** |
| 烧录成功，灯全灭 | 烧完停在暂停态 | 勾 Reset and Run / 命令带 -rst |
| 报 `has no field "BRR"` | F103 的 BRR 在 F4 上不存在 | 清零用 `GPIO_BSRR_BR10` |
| HAL 报 `RCC_HSE_PREDIV_DIV1` 未定义 | F1 专属宏 | 删 SystemClock_Config |
| 绿灯很暗 | 绿光压降 ≈3.0V（红 ≈2.0V），电流只有 1/4 | 正常物理现象 |
| 写成 PC13/GPIOC | F103 板 LED 在 PC13，肌肉记忆 | 以本板原理图为准 |

# 节点二 · 按键控制 LED

## 1. 看图找键

![image-20261015173032108](../../../../../AppData/Roaming/Typora/typora-user-images/image-20261015173032108.png)

**怎么读**：原理图第 3 页（红框=一个按键的完整电路）：左脚接 GND，右脚经 **10K 上拉到 3V3**，
引出网络 KEY1。所以**松开=高电平，按下=低电平（低有效）**。C25 是硬件消抖辅助（软件消抖还是要做）。

![引脚表](images/sch_p7_key_pin.png)

**怎么读**：第 7 页：**KEY1 = PD13、KEY2 = PD14、KEY3 = PD15**。本节点用 KEY1 + LED1。

## 2. 原理

和节点一比只多一件事：**读引脚电平**。

| 步骤 | 要点 |
|---|---|
| 开时钟 | 同节点一（AHB1ENR bit3） |
| PD13 配输入 | MODER **[27:26]** = 00（13×2=26）；板上已有 10K 上拉，**PUPDR 不用配** |
| 读电平 | **GPIOx_IDR**（输入数据寄存器）读 bit13：**0=按下，1=松开** |

![PUPDR](images/rm_p284_pupdr.png)

**怎么读**：第 284 页 `GPIOx_PUPDR`——每脚 2 位：00 无上下拉 / 01 上拉 / 10 下拉。板上焊了上拉，芯片保持 00 即可。

![IDR](images/rm_p285_idr.png)

**怎么读**：第 285 页 `GPIOx_IDR`——每脚 1 位，**只读**，bit 号=脚号。
**IDR vs ODR**：ODR 是"你让它输出什么"，IDR 是"引脚现在真实电平"。读按键永远用 IDR。

**消抖（版本 B 才需要）**：机械按键按下会弹跳 5~20ms。软件消抖 = 检测到按下后**等 20ms 再看一眼**，还是按下才算；然后**等松手**，防长按算多次。

## 3. 寄存器版

### 版本 A：按住亮、松开灭

```c
#include "stm32f4xx.h"

int main(void)
{
    SystemCoreClockUpdate();

    RCC->AHB1ENR |= RCC_AHB1ENR_GPIODEN;   /* 开 GPIOD 时钟 */

    GPIOD->MODER &= ~(3UL << 26);          /* PD13 输入：清 [27:26] 成 00（输入不用写1） */
    GPIOD->MODER &= ~(3UL << 20);          /* PD10 输出：先清 */
    GPIOD->MODER |=  (1UL << 20);          /* 再写 01 */

    GPIOD->BSRR = GPIO_BSRR_BR10;          /* 上电先灭 */

    while (1)
    {
        if (GPIOD->IDR & GPIO_IDR_ID13)    /* bit13：1=松开 */
            GPIOD->BSRR = GPIO_BSRR_BR10;  /* 灭 */
        else                               /* 0=按下 */
            GPIOD->BSRR = GPIO_BSRR_BS10;  /* 亮 */
    }
}
```

### 版本 B：按一下翻转一次（A 通关后再做）

三招：**消抖 20ms → 翻转 → 等松手**。`while(1)` 换成（`delay_ms` 从 `chapters/ch1_led.c` 搬，文件里加 `uint32_t led = 0;`）：

```c
    uint32_t led = 0;

    while (1)
    {
        if ((GPIOD->IDR & GPIO_IDR_ID13) == 0)      /* 检测到按下 */
        {
            delay_ms(20);                           /* 消抖 */
            if ((GPIOD->IDR & GPIO_IDR_ID13) == 0)  /* 还是按下 = 真按 */
            {
                led = !led;
                if (led)
                    GPIOD->BSRR = GPIO_BSRR_BS10;
                else
                    GPIOD->BSRR = GPIO_BSRR_BR10;
                while ((GPIOD->IDR & GPIO_IDR_ID13) == 0) { }  /* 等松手 */
            }
        }
    }
```

## 4. HAL 版

| 寄存器版动作 | HAL 代办员 |
|---|---|
| 读 IDR bit13 | `HAL_GPIO_ReadPin(GPIOD, GPIO_PIN_13)`（返回 RESET=按下 / SET=松开） |
| `ODR ^= OD10` 翻转 | `HAL_GPIO_TogglePin(GPIOD, GPIO_PIN_10)`（自带翻转） |
| BSRR 置位/清零 | `HAL_GPIO_WritePin(...SET/RESET)` |
| 自写 delay_ms | `HAL_Delay`（SysTick 1ms 中断，拿来就用） |

```c
static void MX_GPIO_Init(void)
{
  GPIO_InitTypeDef GPIO_InitStruct = {0};

  __HAL_RCC_GPIOD_CLK_ENABLE();

  GPIO_InitStruct.Pin   = GPIO_PIN_13;           /* KEY1 */
  GPIO_InitStruct.Mode  = GPIO_MODE_INPUT;
  GPIO_InitStruct.Pull  = GPIO_NOPULL;           /* ★板上已有外部10K上拉，内部再配就多余 */
  GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;
  HAL_GPIO_Init(GPIOD, &GPIO_InitStruct);

  GPIO_InitStruct.Pin   = GPIO_PIN_10;           /* LED1（参数单复用，改字段再交一次） */
  GPIO_InitStruct.Mode  = GPIO_MODE_OUTPUT_PP;
  GPIO_InitStruct.Pull  = GPIO_NOPULL;
  GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;
  HAL_GPIO_Init(GPIOD, &GPIO_InitStruct);

  HAL_GPIO_WritePin(GPIOD, GPIO_PIN_10, GPIO_PIN_RESET);   /* 上电先灭 */
}

uint8_t key_pressed(void)
{
  static uint8_t last = 1;
  uint8_t now = (HAL_GPIO_ReadPin(GPIOD, GPIO_PIN_13) == GPIO_PIN_RESET) ? 0 : 1;
  uint8_t evt = 0;

  if (last == 1 && now == 0)                     /* 1->0 = 按下沿 */
  {
    HAL_Delay(10);                               /* 消抖 */
    if (HAL_GPIO_ReadPin(GPIOD, GPIO_PIN_13) == GPIO_PIN_RESET)
    {
      evt = 1;
      while (HAL_GPIO_ReadPin(GPIOD, GPIO_PIN_13) == GPIO_PIN_RESET) { }  /* 等松手 */
      HAL_Delay(10);                             /* 释放消抖 */
    }
  }
  last = now;
  return evt;
}
```

（主循环与寄存器版逐句相同：`HAL_Delay(10)` 节拍 + `HAL_GPIO_TogglePin` 翻转 + 按键开关闪烁。）

**本节点唯一的动脑点**：`Pull` 填 `GPIO_NOPULL`——会看原理图才知道外部上拉已经存在。其余全是把寄存器版动作换成代办员名字。

## 5. 验收

| 腿 | 编译 | 行为 | 体积 | 提交 |
|---|---|---|---|---|
| 寄存器 | ✅ 0错0警 | 按一下开闪 / 再按停（用户自写"按键开关闪烁"，高于原目标） | 848B | `2. 按键控制LED（寄存器版）` |
| HAL | ✅ 0错0警 | 同款，一次过关 | 3336B | `2. 按键控制LED（HAL库版）` |

**常见翻车**：灯常亮不跟手 → 读了 ODR 不是 IDR；按一下翻好几次 → 忘了消抖/等松手；怎么按都没反应 → MODER 忘清 [27:26] 或时钟没开。

# 节点三 · 串口（进行中）

## 1. 看图找串口

![USB转串口电路](images/sch_p3_ch340.png)

**怎么读**：原理图第 3 页"USB转串口"区（红框 = CH340N 芯片）。它一头连 USB-C 口（USB>TTL），
一头连 MCU 的串口——**你插在电脑上的那根 USB-C 线，就是板子的串口**，不需要任何额外接线。

![串口引脚](images/sch_p7_uart_pin.png)

**怎么读**：第 7 页：`CH340_RX → PA9`（板子发→电脑收，PA9 = TX）、`CH340_TX → PA10`（电脑发→板子收，PA10 = RX）。
串口参数 **115200-8-N-1**（波特率-数据位-无校验-停止位，全行业默认款）。

## 2. 原理

### 2.1 波特率：一秒发多少个位

串口没有时钟线，双方靠"约好速度"对齐——这个速度就是波特率。芯片用**分频器**产生它：

![USART 结构图](images/rm_p963_brr.png)

**怎么读**：第 963 页 USART 全家福（红框 = 分频器入口）：你写的字节进 TDR → 移位寄存器一位位发出去；
收到的位进移位寄存器 → 拼成字节进 RDR。TXE/RXNE 就是"发完了没/收到了没"的信号灯。

![BRR 位表](images/rm_p973_brr_bits.png)

**怎么算**（第 973 页位表，DIV_Mantissa 整数 + DIV_Fraction 小数）：

```
USARTDIV = 16,000,000 ÷ 16 ÷ 115200 = 8.6875
整数部分 8   → 写 [11:0] 高段：8 = 0x8
小数部分 0.6875 × 16 ≈ 11 → 写 [3:0]：11 = 0xB
BRR = (8 << 4) | 11 = 0x8B
反推验证：16M ÷ (16 × 8.6875) = 115108，误差 0.08%（<2% 就能正常通信 ✓）
```

对照 F103：72M ÷ 16 ÷ 115200 = 39.0625 → BRR = 0x271。**公式同款，数字不同——又一次"别抄旧板"。**

### 2.2 复用功能：把引脚让给外设

PA9/PA10 平时是普通 GPIO，现在要让 USART1"借走"驱动权：

![GPIOx_AFRH](images/rm_p288_afrh.png)

**怎么读**：第 288 页 `GPIOx_AFRH`（管 8~15 脚，每脚 4 位选一个功能编号）：
两步走——①MODER 写 **10**（复用模式，不是 01 输出了）②AFRH 填 **AF7**（0111 = USART1 的编号）。
PA9 → AFRH [7:4]、PA10 → AFRH [11:8]。（F103 时代没有 AF 编号这回事，这是 F4 的新机制。）

⚠️ **手册名 vs 代码名**：手册里叫 `GPIOx_AFRH`，但头文件 `GPIO_TypeDef` 里它是 **`AFR[2]` 数组**——
`AFR[0]` = AFRL（管 0~7 脚）、`AFR[1]` = AFRH（管 8~15 脚）。所以代码写的是：
```c
GPIOA->AFR[1] &= ~(0xFUL << 4);  GPIOA->AFR[1] |= (7UL << 4);   /* PA9 = AF7 */
GPIOA->AFR[1] &= ~(0xFUL << 8);  GPIOA->AFR[1] |= (7UL << 8);   /* PA10 = AF7 */
```
同款差异还会出现在别的外设上（手册一个名、结构体一个名），查结构体定夺。

### 2.3 三个开关 + 两个信号灯

![CR1](images/rm_p1006_cr1.png)

**怎么读**：第 1006 页 `CR1`：**UE**（bit13，串口总开关）、**TE**（bit3，要发）、**RE**（bit2，要收）。

![SR](images/rm_p1003_sr.png)

**怎么读**：第 1003 页 `SR`：**TXE**（bit7，发送寄存器空了=可以塞下一个字节）、**RXNE**（bit5，收到一字节=快来拿）。
收发全靠盯这两个灯：发前等 TXE=1，看到 RXNE=1 就读 DR。

⚠️ F1 有个"UE 和 TE/RE 必须分两次写"的怪癖；**F4 没有这个问题**，一次写完即可。

### 2.4 铁律：轮询会丢字节

F103 项目实锤事故：轮询收数据时 CPU 忙别的，下一字节到了没被取走 → **ORE 溢出错**，字节白白丢失，
症状是"外设不理人其实是你不收"。所以**正经收数据必须用中断 + 环形缓冲**（版本 B）。

## 3. 寄存器版

### 版本 A：轮询回显（先做这个）

```c
#include "stm32f4xx.h"

int main(void)
{
    SystemCoreClockUpdate();

    RCC->AHB1ENR |= RCC_AHB1ENR_GPIOAEN;     /* ① GPIOA 时钟（AHB1 bit0） */
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;    /* ① USART1 时钟（APB2 bit4） */

    GPIOA->MODER &= ~(3UL << 18);            /* ② PA9 复用：[19:18]=10 */
    GPIOA->MODER |=  (2UL << 18);
    GPIOA->MODER &= ~(3UL << 20);            /* ② PA10 复用：[21:20]=10 */
    GPIOA->MODER |=  (2UL << 20);
    GPIOA->AFRH &= ~(0xFUL << 4);            /* ② PA9 = AF7：[7:4] */
    GPIOA->AFRH |=  (7UL << 4);
    GPIOA->AFRH &= ~(0xFUL << 8);            /* ② PA10 = AF7：[11:8] */
    GPIOA->AFRH |=  (7UL << 8);

    USART1->BRR = 0x8B;                      /* ③ 115200 @16MHz */

    USART1->CR1 = USART_CR1_UE               /* ④ 总开关+发+收，一次写 */
                | USART_CR1_TE
                | USART_CR1_RE;

    while (1)
    {
        if (USART1->SR & USART_SR_RXNE)      /* ⑤ 收到一字节？ */
        {
            uint8_t c = USART1->DR;          /* 读 DR 自动清 RXNE */
            while (!(USART1->SR & USART_SR_TXE)) { }   /* 等发送寄存器空 */
            USART1->DR = c;                  /* 原样发回（echo） */
        }
    }
}
```

### 框架

```
上电
 │
 ├─ 1. SystemCoreClockUpdate()     更新时钟变量
 ├─ 2. 开 GPIOA 时钟（AHB1 bit0）
 ├─ 3. 开 USART1 时钟（APB2 bit4）
 ├─ 4. 配 PA9/PA10 为复用模式
 ├─ 5. AFR[2]（PA0~PA15） 选 AF7（USART1） c（PA0~PA7）AFR[1]（PA8~PA15）
 ├─ 6. 设波特率 BRR = 0x8B（115200）
 ├─ 7. 使能 USART1：UE + TE + RE
 ├─ 8. 发欢迎字符串
 │
 └─ while(1)
      ├─ 等 RXNE=1（收到字节）
      ├─ 读 DR（自动清 RXNE）
      ├─ 等 TXE=1
      └─ 写 DR（发回去）
```

### 版本 B：中断 + 环形缓冲（版本 A 验收过了再做）

![image-20261019085956628](../../../../../AppData/Roaming/Typora/typora-user-images/image-20261019085956628.png)

![image-20261019090019452](../../../../../AppData/Roaming/Typora/typora-user-images/image-20261019090019452.png)

```c
#include "stm32f4xx.h"

#define BUF_LEN 64
volatile uint8_t  rbuf[BUF_LEN];
volatile uint16_t rhead = 0, rtail = 0;      /* 写指针 / 读指针 */

void USART1_IRQHandler(void)                 /* 函数名=向量表名，一字不能差 */
{
    if (USART1->SR & USART_SR_RXNE)
    {
        rbuf[rhead] = USART1->DR;            /* 中断里只做一件事：存起来就走 */
        rhead = (rhead + 1) % BUF_LEN;
    }
}

int main(void)
{
    /* ……初始化同版本 A，另加两行： */

    USART1->CR1 |= USART_CR1_RXNEIE;         /* 收到字节就触发中断（CR1 bit5） */
    NVIC->ISER[1] = 1UL << (37 - 32);        /* USART1 中断号 37，挂到 NVIC */

    while (1)
    {
        if (rtail != rhead)                  /* 缓冲区有货？ */
        {
            uint8_t c = rbuf[rtail];
            rtail = (rtail + 1) % BUF_LEN;
            while (!(USART1->SR & USART_SR_TXE)) { }
            USART1->DR = c;                  /* 回显 */
        }
    }
}
```

**两行中断使能代码，凭什么这么写**（中断要过两道门，每道都有手册依据）：

一道门在**外设**（USART1 要"愿意举手"）：

![CR1 RXNEIE](images/rm_p1005_cr1rxneie.png)

**怎么读**：RM0090 第 1005 页 CR1 位表——**bit5 = RXNEIE**（收到一个字节就触发中断的允许位）。
`USART1->CR1 |= USART_CR1_RXNEIE` 就是把它写 1：以后每收到一个字节，USART1 就向 CPU"举手"。

一道门在 **CPU**（NVIC 要"愿意接"）。先查 USART1 的**中断门牌号**——它刻在向量表里：

![向量表](images/rm_p375_vector_usart1.png)

**怎么读**：RM0090 第 375 页 **Table 62「Vector table for STM32F405xx/07xx」**（我们 F407 正属这个家族），
红框行：**位置 37 = USART1**。门牌号 37 是芯片出厂就刻死的，只能查表，不能算。

再看 CPU 这边的开关墙——注意 **NVIC 是 ARM 内核的东西，RM0090 里没有，要查另一本手册 PM0214**（已下载在
`手册下载/PM0214_CortexM4编程手册.pdf`）：

![PM0214 ISER](images/pm0214_p210_iser.png)

**怎么读**：PM0214 第 210 页 §4.3.2：NVIC 有 **8 个 ISER 寄存器**（地址 0x100 + 0x04×x），**每个管 32 个中断**——
ISER[0] 管 0~31 号，ISER[1] 管 32~63 号，以此类推。USART1 是 37 号，落在 32~63 区间 → **用 ISER[1]**，
它内部的位号 = 37 − 32 = **5**。所以：

```c
NVIC->ISER[1] = 1UL << (37 - 32);   /* = 1UL<<5：把 ISER[1] 的 bit5 置 1 = 允许 37 号(USART1)中断 */
```

两道门全开，中断才会真正进来——少任何一道，字节到了也无人应答。

**环形缓冲是什么**：一个 64 字节数组 + 两个指针——中断往 `rhead` 写，主循环从 `rtail` 读，
谁也不等谁。中断来的再快也只是"把缓冲填满"，主循环忙别的也不会丢字节。这就是 F103 血泪换来的正确姿势。

2. 版本 A：随便发字符 → 收到原样回显
3. 版本 B：快速连发一串 → 一个字节都不丢

**"打印信息怎么就有了"**（版本 B 实测后的真问题）：板上没有任何打印函数。屏幕上每行"收←"都是
**你自己发的那条走一圈回来的**：SSCOM 发 → CH340 → PA10 → 中断存环形缓冲 → 主循环取出 → 写 DR →
移位寄存器自动按 115200 搬到 PA9 → CH340 → SSCOM 显示。**写 DR = 发送**，这是串口唯一动作；
`uart1_str()` 也只是循环塞 DR。S:27=R:27 就是"收到的全是发出去的"铁证。
（注意：CH340 重插后 COM 号会变——COM7 变 COM8，每次测试先看一眼端口号。）
